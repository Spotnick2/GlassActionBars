# Glass Action Bars

The liquid-glass look of the Glass addons for **World of Warcraft: Forever**'s own action bars.
It keeps Blizzard's bars, so paging, key bindings, Edit Mode and cooldowns work exactly as they
always do; only the look changes.

![The mockup: three rows of glass action buttons, a block of twelve beside them, and a small bar of consumables at the end](https://raw.githubusercontent.com/Spotnick2/GlassActionBars/main/docs/mockups/action-bars.png)

**Status: in development.** The plan is [docs/PLAN.md](docs/PLAN.md):

- **v0.1.0**: the glass skin on the main bar, the seven extra bars, the stance bar and the pet bar.
- **v0.2.0**: smart bars docked to the end of a bar (a Utility bar with your Hearthstone and
  professions), and an API so other addons (Apotheca, 123, Portal Roulette) can dock their bars
  and buttons there.

## Install

Install **Glass Action Bars** from
[CurseForge](https://www.curseforge.com/wow/addons/glass-action-bars), either with the
CurseForge app or by unzipping it into the `Interface\AddOns` folder inside your Forever game
folder. Then `/reload`, or start the game.

`/gab help` lists the commands.
